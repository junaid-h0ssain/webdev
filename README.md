# WebDev Projects

A collection of front-end web development projects showcasing HTML, CSS, and JavaScript skills.

## Projects

### Birthday Card
An interactive animated birthday card with falling gift boxes, background music, and playful messages.
- **Tech:** HTML, CSS, Bootstrap 5, JavaScript
- **Features:** CSS animations, audio playback, responsive design

### Business Card
A clean, stylish digital business card component.
- **Tech:** HTML, CSS
- **Features:** Card layout, image styling

### Google Homepage Clone
A recreation of the classic Google search homepage.
- **Tech:** HTML, CSS
- **Features:** Search input styling, button components

### Space Exploration
A space-themed landing page with custom typography and call-to-action elements.
- **Tech:** HTML, CSS, Google Fonts
- **Features:** Custom fonts, hero section, CTA buttons

### Local City (Chittagong)
A tourism landing page showcasing the city of Chittagong with notable attractions.
- **Tech:** HTML, CSS
- **Features:** Hero section, card grid layout, image galleries

### Vanilla Firebase
A vanilla JavaScript project integrated with Firebase.
- **Tech:** HTML, JavaScript, Firebase
- **Features:** Firebase integration, environment configuration

### JS Learning
A sandbox for learning and experimenting with JavaScript/TypeScript.
- **Tech:** HTML, JavaScript, TypeScript

## Getting Started

1. Clone the repository
2. Open any project's `index.html` in your browser
3. For TypeScript compilation:
   ```bash
   npm install
   npm run build
   ```

## Tech Stack

- HTML5
- CSS3
- JavaScript
- TypeScript
- Bootstrap 5
- Firebase
